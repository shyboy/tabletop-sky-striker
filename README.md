# 借风计划 · 桌面飞机大战 (Tabletop Sky Striker)

> **在线即玩（GitHub Pages 原生 HTTPS）**：[https://shyboy.github.io/tabletop-sky-striker/](https://shyboy.github.io/tabletop-sky-striker/)  
> **灵感致敬**：`@noshipu` 实体玩具 + 平板视错觉互动  
> **定位**：内置**《借风计划》三幕航行故事**，支持**手机扫码座舱遥控 / 陀螺仪体感飞行杆 / 吹气顺风清屏 / 蓝牙手柄**的网页端双模飞机大战

## 故事背景：《借风计划》

书桌上的合金小车、折纸飞机和旧橡皮自己没有引擎，也没法飞出窗外。  
把屏幕变成一扇通往云海的天窗——**既然桌上的小家伙自己飞不动，那就让整片云层、海岛、晚霞和星空替它往后奔跑。** 握起手机当无线操纵杆，你对着麦克风吹出的每一口气，都是托起它的八级顺风：

1. **第一航段 · 晴空借风**（白昼晴空）：穿越碧海岛链，冲破“灰雾封锁舰”对天窗的遮蔽。
2. **第二航段 · 暮色穿云**（金橙晚霞）：突入落日风暴带，用磁轨炮与顺风撕开“风暴铁幕舰”的弹幕封锁。
3. **第三航段 · 星海灯塔**（深空极光）：驶入静谧星海，守住桌面上最后一扇亮着光的云端天窗。

## 两种启动方式

### 方式 A：在线直接开玩（推荐 · 免安装）
1. 在平放桌面的 iPad / 平板或电脑浏览器打开：[https://shyboy.github.io/tabletop-sky-striker/](https://shyboy.github.io/tabletop-sky-striker/)
2. 点击「📱 手机扫码遥控」，用手机系统相机或浏览器扫码即可通过 WebRTC 无线配对。因为 GitHub Pages 原生具备受信任 HTTPS 证书，无需手动信任证书即可直接开启**手机陀螺仪体感飞行杆**与**麦克风真吹气清屏**。

### 方式 B：本地局域网极速模式（零外网依赖 · 2ms 级延迟）
1. 克隆本仓库后，Windows 双击运行 [启动桌面飞机大战.bat](./启动桌面飞机大战.bat)（或跨平台执行 `node server.mjs`，零 npm 依赖）。
2. 打开大屏主战场：`http://localhost:8780`（桌面平板可通过电脑局域网地址如 `http://192.168.x.x:8780` 打开）。
   - **极速直连 (`HTTP:8780`)**：零证书弹窗，毫秒级 WebSocket 直连摇杆、下拉磁轨炮、核弹与点按清屏。
   - **传感器增强 (`HTTPS:8781`)**：在扫码面板下拉切换为 HTTPS 地址（首次在手机浏览器点“高级 → 继续访问”），即可在局域网内解锁手机陀螺仪与麦克风吹气。

## 核心玩法与交互细节

### 1. 主界面、无遮挡侧边栏校准与自动暂停
- **主界面留空停机坪**：主界面上半屏展示《借风计划》航行简报与模式选择，屏幕下方 `75%` 处留出通透的金色呼吸停机坪——先把真小车/纸飞机摆进框内，再点击大屏或手机上的 **「🚀 点火起飞」**。
- **侧边停靠透视检查器 + CAD 实时标尺**：点击「🎯 校准底座」打开左侧（可一键切换至右侧）无遮挡面板，屏幕中央自动隐藏卡片并亮起**机械制图级 `W × L px` 双轴尺寸标尺与实物半透明轮廓**，拖动滑块即可边看边贴合真车边缘。
- **设置自动暂停 & 一键停止返航**：大屏或手机端打开设置/校准抽屉时战局自动悬停，关闭自动恢复；顶部工具栏、暂停面板、结算页与手机座舱均提供 `⏸ 暂停` 与 `⏹ 停止返航` 按钮。

### 2. 双模一键切换（控制背景 vs 控制战机）
- **实体压屏模式（默认主打 · 动背景）**：
  - 停机坪渲染**金色校准框、随转向反偏的动态接触假阴影、机头火光、随惯性甩尾的双发马赫尾焰与两侧贴边自律浮游炮**。
  - 把家里的**合金小车、玩具战机、折纸飞机或瓶盖/橡皮**直接放在屏幕停机坪里。推动摇杆或倾斜手机时，三层高低云海与海岛按 `2.5D` 视差反向流动，空域轻微横滚 `±7.5°`。
- **纯屏街机模式（动虚拟飞机）**：
  - 身边没玩具时，在主界面、暂停菜单、手机端或按键盘 `M` / 手柄 `△(Y)` 无缝切换为驾驶虚拟战机自由穿梭。
- **亲子护航模式**：开启后受击触发护盾抵消而不爆机，适合带小朋友畅玩。

### 3. 纯净实拍模式 + 手机座舱战术仪表盘
- **实拍纯净模式**：在暂停菜单点「📷 实拍纯净」（或手机端「实拍」、键盘 `H`），隐藏全部 UI 按钮与文字，方便架相机拍摄平板上真玩具喷火穿云的视频。
- **手机端座舱 MFD**：
  - **实时战术雷达与航段仪表**：20Hz 同步显示当前航段名称、借风里程（`km`）与敌机/Boss 方位。
  - **下拉蓄力磁轨炮**：按住导轨拉栓往下拉，大屏实物机头前聚拢电弧球与激光瞄准线，松手轰出贯穿全屏的高能电浆主炮。
  - **四态智能主控大钮**：主界面为「🚀 点火起飞」，暂停时为「▶ 继续航程」，战斗中为「☢ 战术核弹」，迫降结算时为「↻ 再次升空」。
  - **八级顺风清屏（吹气 / 点按）**：对着手机麦克风吹一口气（或点按顺风键），大屏掀起呼啸气旋将敌弹倒吹反砸敌机，并吸来全屏道具。

### 4. 战斗内容（v1.1 丰富版）
- **三位各具特色的封锁舰 Boss**，血量过半进入**狂暴阶段**（换弹幕、提速、红色过载光环），顶部显示 Boss 名称与血条：
  - 灰雾封锁舰：环形弹、双侧瞄准、只留一道缺口的「灰雾幕墙」，狂暴后加入双螺旋。
  - 风暴铁幕舰：黄色虚线预警后劈下的**闪电走廊**（同时会劈伤杂兵），扇形弹与机翼风暴墙。
  - 深空母舰：机库弹射护航侦察机、花瓣螺旋、双层环形弹，狂暴后正反双螺旋。
- **七种杂兵**按航段逐步登场：侦察机、炮艇、冲锋枪骑、正弦编队「织云机」、投放水雷的轰炸机、原地旋转弹幕的「哨塔」，以及靠近才会引爆的**浮空水雷**。
- **新道具**：`S` 能量护盾（最多两层，抵挡一次伤害）、`D` 浮游僚机（2→4 架编队）、`P` 火力、`+` 修复、`N` 核弹。
- **金星连锁**：击落敌机掉落金星，连续拾取价值从 100 一路涨到 1000，漏掉一颗就重置。
- **连击倍率**：右上角连击计，每 25 连击有提示音与特效。
- **通关结局 + 无尽航线**：击败第三幕深空母舰后放慢镜头、烟花庆祝，随后进入循环三种天空、难度与奖励递增的无尽航线。
- **结算评级与本地纪录**：结算页显示 S/A/B/C 评级、击落数、最高连击、金星数，并在主界面展示历史最佳分数与最远里程（保存在浏览器本地）。

### 5. 借风玩法与 Boss 弱点（v1.2）
- **呼吸就是引擎**：对手机麦克风**持续轻吹**＝顺风推进（迎面敌弹被吹慢、道具被吸过来，真吹气还会加速充能大顺风）。吹气有**肺活量**：一直吹会耗尽、进入「换气中」，停下来才会回满，左上角显示计量；**用力一吹**＝大顺风，威力随吹气力度分为小顺风 / 八级顺风 / 十级狂风。键盘按住 `F`、手柄按住 `□/X` 也能模拟轻吹。
- **每个 Boss 都有吹气 / 磁轨炮弱点**：灰雾封锁舰被灰雾护甲减伤 65%，吹气或核弹吹散护甲后才能全力输出；风暴铁幕舰的闪电走廊可以被顺风吹偏；深空母舰放出的护航机可以被倒吹回机库造成重创；**完美蓄力**：磁轨炮拉满后 0.45 秒内松手（机头出现「松手！」，手机轻震）会打出更宽更强的光束，对狂暴核心伤害翻倍；拉满后一直不放会「过热」掉威力。
- **凯旋时刻**：通关三幕后出现凯旋卡片，可选择「继续无尽航线」或「降落停机坪 · 查看航志结算」（手机座舱同样提供这两个选项）。
- **三档难度**：🧸 轻松（小朋友：开局送护盾、机体缓慢自修、敌弹更慢更痛感更低）/ ✈️ 标准 / 🔥 王牌，可与「亲子护航」无敌模式叠加；选择会记住。
- **实物友好提示**：真玩具会挡住身下的子弹，所以实物周围会亮起指向来弹方向的红色弧光；闪电预警、水雷启动、Boss 狂暴时手机还会以不同节奏震动。
- 评级改为看受击次数（通关且受击 ≤ 4 次才是 S），被击中会中断金星连锁；敌机射击带提前量，持续横移不再能无伤躲开。

### 6. 玩具个性、受击判定、家长地勤与纪念卡（v1.3）
- **玩具个性**：主界面选择放上桌的是什么，并给它起个名字（显示在起飞提示与纪念卡上）：
  - ✈️ 飞机 · 灵巧型：横移更快、射速更高、判定最小，但机体只有 90；翻滚冷却更短。
  - 🚗 小车 · 坦克型：机体 140、子弹更重；撞上小型敌机会直接把它「撞飞」。
  - 🧿 瓶盖 · 守护型：自带一颗环绕护卫球拦截敌弹，顺风充能快 25%。
- **受击判定核心**：只有实物正中央的红白判定点碰到子弹才算受伤（不再随实物尺寸放大），子弹擦过机身只会加擦弹分；校准面板可选判定大小「小 · 高手 / 标准 / 大 · 更直观」，打开校准时会标出判定半径。
- **家长地勤（第二台手机）**：在「手机扫码遥控」页展开「家长当地勤」扫第二个二维码（`crew.html?room=房间号`）。孩子用第一台手机飞，家长可以投放护盾、远程维修、空投补给，点雷达标记敌机（僚机优先集火、受到伤害 +50%），还能给孩子发加油表情。
- **航程纪念卡**：结算页点「📸 生成航程纪念卡」，生成一张包含玩具名字、三幕航线、评级与数据的纪念图，可保存或分享。

### 7. 新手引导、节奏与界面（v1.4）
- **首航新手引导**：第一次起飞会进入 7 步引导（移动 → 自动开火 → 吃道具 → 躲子弹 → 顺风 → 磁轨炮 → 核弹/翻滚），每一步都要真的做到才进入下一步（有超时，不会卡住），引导中被击中不扣血；可随时「跳过引导」。提示文字会根据你手里的设备显示手机座舱 / 触屏 / 键盘手柄的操作，手机座舱上对应的按钮会闪烁高亮。
- **首次提示**：第一次遇到某种敌机、第一次吃到某种道具、第一次血量告急时，会弹出一张小卡片说明它的作用（每台设备只讲一次，可在「玩法说明」里重置）。
- **玩法说明**：主界面与暂停菜单里的「📖 玩法说明」列出全部操作、道具、敌机与 Boss 弱点，并可重新体验新手引导。
- **循序渐进的节奏**：Boss 不再按分数提前出现，每一幕都会先飞满约 1.5～2.5 分钟（左上角金色进度条），新敌机按航段进度逐个登场，敌机火力与密度随进度平滑上升；三幕全程约 8～10 分钟。
- **越飞越强**：开局 Lv1 火力、无僚机，火力上限随航段提高（第一幕 Lv2 → 第二幕 Lv3 → 第三幕 Lv4 → 无尽航线 Lv5），受击不再掉火力；每幕中途有补给空投，打败封锁舰后永久强化（耐久上限 +15、僚机 +1、核弹 +1）。
- **更干净的战场**：飞行中右上角只保留一个圆形暂停键，模式、背景、音效、实拍、校准、扫码都收进暂停菜单；左上角 HUD 缩小并半透明，战机飞到下面时自动淡出；没有连手机的触屏设备会在两个下角显示顺风 / 翻滚 / 磁轨 / 核弹按钮。
- **战机与子弹更醒目（参考东方 / CAVE / 雷电的做法）**：飞行中背景自动压暗、云层与海岛淡化、阳光与速度线减弱（速度线和星星最像子弹）；敌弹统一为「彩色光晕 + 黑边 + 白芯」并画在最上层（压在爆炸、尾焰、顺风气流和战机之上）；自己的子弹统一为青白色长条，不再与橙红色敌弹撞色；虚拟战机加深色描边，战机身后有一圈暗区防止被白云吞没；全屏闪白减弱。暂停菜单可把「背景亮度」调为 标准 / 压暗 / 很暗。背景两侧有柔和的云带，中间留出一条缓缓弯曲的干净通道，零散的云和海岛会从通道中央淡出，飞行更有通道感。
- **手机不再误缩放**：大屏、手机座舱、家长地勤三个页面都禁用了双击放大与双指缩放。

### 8. 画面与音效
- 晴空太阳光晕、暮色落日与雷暴闪电、深空星空与极光；纯屏街机模式下背景也会随航程滚动。
- 爆炸火球、烟雾、碎片与冲击波，发光弹幕，低血量红色警示暗角。
- 纯代码合成的**四段背景音乐**（主界面 / 晴空 / 暮色 / 星海），Boss 战自动加入鼓点，暂停时静音；新增护盾、金星、闪电、水雷、狂暴、胜利等音效。

### 9. 蓝牙手柄与键鼠直连支持
- **PS5 / Xbox / Switch 手柄**（原生 `Gamepad API` 含双马达震动）：
  - `Options/Start` 点火起飞或暂停 · 左摇杆移动 · `R2/RT` 或 `×/A` 开火 · 按住 `L2/LT` 蓄力磁轨炮 · `□/X` 顺风清屏（按住＝轻吹顺风） · `○/B` 战术核弹 · `L1/R1` 翻滚躲弹 · `△/Y` 切换双模
- **键盘/鼠标**：
  - 主界面 `Enter`/`Space` 点火起飞 · 飞行中 `P`/`Esc` 暂停 · 鼠标按住画布拖拽飞行 · `WASD`/方向键移动 · 按住 `Shift`/`J` 蓄力磁轨炮 · `F` 顺风清屏（按住＝轻吹顺风） · `K`/`Enter` 战术核弹 · `Space` 翻滚无敌 · `M` 切换双模 · `H` 实拍纯净 · 通关卡片上 `L` 降落结算

## 目录结构

- `index.html` — 大屏主战场页面（含主界面停机坪、侧边栏透视校准器、故事简报与借风航志结算面板）
- `controller.html` — 手机座舱 MFD 遥控器页面
- `crew.html` / `js/crew-app.js` — 家长地勤指挥台（第二台手机）
- `js/flight-card.js` — 航程纪念卡生成与预览/保存
- `js/game-engine.js` — 双模 `2.5D` 视差物理、CAD 校准标尺、三幕天气光影与暂停状态机引擎
- `js/controller-app.js` — 手机端阻尼摇杆、体感归零、拉栓蓄力、吹气检测与远程暂停/起飞/返航控制
- `js/link-bridge.js` — 多通道通信桥（同机 `BroadcastChannel` + 本地 `WebSocket` + 公网 `PeerJS` WebRTC 自动回退）
- `js/qrcode-mini.js` — 纯前端离线 SVG 二维码编码器
- `js/no-zoom.js` — 手机 / 平板页面的防双击放大与防双指缩放
- `js/sound-fx.js` — Web Audio API 纯代码实时合成音效与分章节背景音乐库
- `server.mjs` — 零依赖 Node.js 本地服务（过滤代理虚拟网卡、纯内置 `crypto` 自签名 HTTPS 证书、原生 RFC 6455 WebSocket 毫秒级房间中继）
- `启动桌面飞机大战.bat` — Windows 本地一键双协议启动器
