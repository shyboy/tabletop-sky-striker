# 桌面飞机大战 · 战斗数值与技能构筑表

这一版以**标准难度、无地勤、无护盾、无技能**为基线。把移动、命中率和走位算进去之前，先用固定的齐射、击中次数和伤害类型对齐手感。表中的“致命命中”包含最后一次命中，假设中间没有治疗、每次均在受击保护结束后发生。

> **技能强度系数（`powerScale`）**：`= (1 + (主炮等级 - 1) × 0.12) × 机体伤害倍率 × 全局增伤倍率`。所有主动/召唤伤害技能（导弹、飞剑、风刃、环轨球、闪电链底伤、电离余震、脉冲新星、反弹弹）均乘该系数，使技能伤害在第二、三幕及无尽航线保持合理占比。

## 升级、抽卡编排与 23 张技能构筑

- **经验曲线**：首升（Lv.1→2）固定 **36 XP**（9 架侦察机，或 1 架轰炸机 + 1 架炮艇）。Lv.2+ 所需经验为 `round(28 + 当前等级 × 20 + (当前等级 - 1)^1.32 × 5)`。Lv.1→10 依次需 `36 / 73 / 100 / 129 / 159 / 190 / 221 / 253 / 286 / 319`，正常三幕每幕稳定获得 **3–4 次选卡**。
- **智能抽卡编排（Smart Draft Director）**：
  1. **首抽保护**：Lv.2 首次选卡屏蔽纯被动边缘辅助卡（磁极/肺活量/擦弹），3 张候选必出自 3 个不同流派且含直接战技。
  2. **构筑聚焦与槽位收敛**：已持有 1★ 技能权重 `×1.8`、2★ 技能权重 `×1.55`，同流派技能享共鸣加成；持有 ≥5 种基础技能后降低新散件权重，帮助玩家稳定凑出 2★/3★ 核心而非满身 1★ 散件。每批三选一至少保底 1 张输出向技能，避免同流派扎堆。
  3. **阶梯式五流派觉醒**：五大流派各有 1 张专属金色传说觉醒卡（1 星封顶）。对应流派**任一技能达 2★** 后满足前置，按等级阶梯开放觉醒槽：**Lv.5 开启第 1 觉醒 → Lv.8 开启第 2 觉醒 → Lv.11 开启第 3 觉醒（封顶 3 阶流光翼）**。
  4. **无尽满池超频**：当可选池抽空时，每次升级自动转化发放「核心超频」（全伤害永久 +6%，并回复 35% 耐久与 1 层护盾）。
